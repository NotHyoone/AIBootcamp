  • Major · Diary Simple 테스트 2개 실패. simple.test.cjs:35의 분리 VM은 simpleOverview에 필요한 isDiary를 제공하지 않습니다. :46부터의 삭제 테스트는 함수 종료 문자열로 코드를 잘라내며 현재 소스에서 유효한 블록을 얻지 못해 ‘co is not defined’가 발생합니다. 전체 브라우저 결과 화면은 정상 렌더됐지만 삭제 동작 자체는 이번에 검증하지 않았습니다. 테스트 실패를 실제 앱 삭제 오류로 단정하지 않습니다.
  • Major · 운영 분석 미연결. 루트 README의 기존 6분류 API와 이 프론트들의 3+7 분류 계약이 다릅니다. 실제 분석 서비스를 완성하려면 계약 확정과 API 통합이 필요합니다.
  • 유지보수 · 독립 복제본의 증가. 도메인·화면·테마 변경이 여러 폴더에 분산됩니다. v2→v3 scripts 차이는 core.js 표시명 한 줄이고, v3→v4는 app.js UX 변경입니다. 기준 버전을 정한 뒤 공통 코드화 범위를 검토하는 편이 좋습니다.
  • 검증 범위. 8개 앱의 시작 화면과 예시 결과를 실제 Chrome으로 열었습니다. 결과 화면 16개 조건에서 페이지 JavaScript 오류와 문서 가로 넘침은 없었습니다. 클릭 전수·다크 모드·320px·실기기·키보드 전체·스크린리더·대비·PNG 저장·Web Share·새 탭 E2E는 이번 검증 범위 밖입니다.
