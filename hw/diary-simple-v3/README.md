# MOMENT CARD · Diary Simple v3

Diary Simple v2의 기록 입력·대표 카드 화면에 Integrated TCG의 상세 분석 구성을 연결한 독립 프론트입니다.

## 실행

**`index.html` 하나만 브라우저에서 열면 됩니다.** CSS·JS·폰트·폰트 라이선스가 내장되어 있으며 서버, 인터넷, 패키지 설치가 필요하지 않습니다. 팀원에게는 이 HTML 파일 하나를 전달하세요.

1. 첫 화면에서 기록 입력을 확인합니다.
2. ‘예시 카드 미리 보기’를 펼치고 ‘날짜 있는 기록 4개’를 선택합니다.
3. 대표 감정 카드에서 ‘상세 분석 보기’를 누릅니다.
4. 분석 요약·분포·흐름·캘린더·일/주/월·반복 표현·도감·종합 설명을 탐색합니다.
5. ‘내 감정 카드’로 돌아가거나 ‘이 결과 공유’에서 PNG를 저장합니다.

**운영 3+7 일기 모델은 미연결입니다.** 사용자 입력은 검증·내용 확인·연결 대기까지 동작하며 외부 전송하지 않습니다. 예시 버튼으로 연 결과는 입력한 글의 분석 결과가 아닙니다. 캐릭터 이미지 자산은 승인 대기 상태입니다.

## 반영한 설계

- 기본 화면: v2의 날짜/기록 입력, 입력별 오류와 포커스, TXT 추가 시 기존 기록 보존, 대표 카드, 접을 수 있는 공유 설정 유지.
- 상세 분석: Integrated TCG의 2열 요약, 3/7분포, 흐름, 날짜 미리보기, 반복 표현 정렬·등장 비율·원본 근거를 일기 데이터에 맞게 이식.
- 공통 데이터: `state.result` 하나로 카드·상세·공유를 표시. 다른 버전 파일이나 별도 앱을 열지 않음.
- 같은 탭 이동: `#overview`는 간단한 카드, `#analysis`는 통합 상세 요약. 모바일과 로컬 파일 실행에서 새 창 전달 없이 돌아올 수 있음.
- 단일 기록: 분포·도감·공유 제공, 추이·기간·캘린더·반복 표현에는 제한 사유 표시.
- 날짜 없는 복수 기록: 기록 순서 흐름과 반복 표현 제공, 기간·캘린더에는 날짜 없음 안내. 날짜를 추정하거나 빈 날짜를 0%로 채우지 않음.
- 새로고침: 입력·분석 결과 초기화, 결과 없는 상세 경로는 복구 안내 표시. 표시 모드만 v3 전용 키에 저장.
- 공유: 전체 분석 기준. 원문·반복 표현 원본·파일명 등은 공개 출력에 포함하지 않음.

## 소스와 빌드

| 경로 | 역할 |
|---|---|
| `index.html` | 단독 실행·전달용 산출물 |
| `templates/shell.html` | HTML 틀 |
| `scripts/core.js`, `diary-core.js` | 원본 집계·확률·입력 검증·예시 계약 |
| `scripts/app.js` | v2 기반 입력·분포·흐름·기간·캘린더·도감·공유와 상태 |
| `scripts/integrated.js` | 카드 우선 화면·상세 통합 요약·공통 탐색·날짜 바로가기 |
| `scripts/theme.js` | v3 전용 테마 설정 |
| `styles/base.css` | v2 기반 스타일과 내장 폰트 |
| `styles/integrated.css` | Integrated TCG 상세 대시보드 스타일 |
| `styles/refinements.css` | 기본/상세 화면과 모바일 탐색 조정 |
| `tools/build.mjs` | 모든 소스와 라이선스를 단일 HTML로 생성 |
| `tests/` | 도메인 회귀 및 실제 브라우저 통합 검사 |

```powershell
node hw/diary-simple-v3/tools/build.mjs
node --test hw/diary-simple-v3/tests/core.test.cjs hw/diary-simple-v3/tests/diary.test.cjs
node hw/diary-simple-v3/tests/browser.cjs
```

Node 빌드는 외부 패키지가 필요하지 않습니다. 브라우저 검사에만 Playwright와 설치된 Chrome이 필요합니다. `CARDEX_PLAYWRIGHT`, `CARDEX_CHROMIUM`, `CARDEX_QA_OUTPUT`으로 패키지·실행 파일·결과 저장 경로를 지정할 수 있습니다. 기본 검사 환경은 Windows Chrome과 임시 `aibootcamp-frontend-review/node_modules/playwright`입니다.

## 검증

도메인·일기 입력 계약 **30개 통과**. 오프라인 Chrome에서 단일 HTML만 다른 폴더로 복사해 검사했습니다.

- 입력 오류 위치·삭제·내용 확인·분석 미연결 대기 확인.
- 대표 카드 → 통합 상세 → 날짜/기간/반복 표현/도감 → 공유 → 같은 상세 복귀 확인.
- 카드와 상세·공유 이동 후 전체 확률·표본이 유지됨을 확인.
- 원문 비공개와 실제 1080×1350 PNG 다운로드 확인.
- 단일/날짜 있는 복수/날짜 없는 복수 × 10개 경로 × 320/390/1440px = **90개 조건에서 페이지 가로 넘침 없음**.
- 라이트/다크 캡처 확인. 외부 HTTP 요청과 페이지 JavaScript 오류 없음.
- 새로고침 뒤 과거 예시 결과가 재생성되지 않고 복구 안내가 표시됨을 확인.

실기기, Safari·Firefox, Web Share·클립보드 권한별 동작, 스크린리더와 WCAG 전체 적합성은 검증하지 않았습니다. 모델 추론과 장기 저장은 구현 범위 밖입니다.

## 원본 관계

기존 버전은 수정하지 않았습니다. v2의 내장 소스를 분리하여 유지보수 가능한 빌드 경로를 추가했고, Integrated TCG의 상세 레이아웃·반복 표현 탐색 코드를 이식했습니다. 일기 데이터의 분모와 날짜·단일 기록 제약은 유지합니다. v1/v2의 새 탭 전달 코드는 같은 탭 탐색으로 교체했습니다.
