## 적용 범위

- GitHub HW의 `hw/emotion-cardex-v3/`에 v2를 복사해 적용. v1·v2·기존 루트 구현은 변경하지 않았다. 기준 커밋 `c484af0dd3dc0c21192dce23f3ec56e5442e2dfd`.
- `scripts/core.js`의 `TYPES`에서 pos_3의 `name`만 수정했다. 검색·카드·확대·분포·범례·로컬 사실 설명이 같은 원천을 참조한다.
- 종합 계획의 매핑 표와 이번 개정 문서를 수정하고, 내장 폰트에 필요한 글리프 및 단독 `index.html`을 다시 생성했다.
- Figma 파일 `gITGJDkuTzV3rWFKmj5wLz`에 **V3_00_Overview_and_Plan / V3_01_Foundations / V3_02_Desktop / V3_03_Mobile / V3_04_Tablet** 5개 복제 페이지를 추가했다. 기존5개 페이지와 원래 TCG 참조 파일은 보존했다. Figma는 라이트 시안이며 HTML은 라이트·다크·시스템을 지원한다.
- 승인되지 않은 캐릭터 이미지는 생성하지 않았다. 과거 다른 테마 전체의 명칭을 개정했다고 주장하지 않는다.

‘안정성’, ‘안정된 ID’는 기술적 표현으로 유지했다. 변경 이력에서 이전 명칭을 쓰는 것은 허용한다. 첨부 SRS/SDS 원본에 남아 있는 과거 표시명은 원본 보존 정책에 따라 편집하지 않았으며, 이 UI에는 최신 공통 지침이 우선한다.

## 유지한 값

ID·번호·부모 positive/negative/neutral·3/3/1 구조·확률·대표 계산·분모·발화 범위·윈도우·축·결측·API 계약·`taxonomy_version`을 유지했다. 변형·희귀도·획득 기능을 추가하지 않았다. 이전6분류 운영 API를7분류로 임의 매핑하지 않는다.

## 수행한 검증

- 데이터/명칭 단위 검사 **22개 통과**: 기존18개와 신규4개. 7명칭·ID/번호/색/패턴/부모 동일, 5종 시나리오의 원본 예시 JSON 동일, 평온 검색과 로컬 설명 확인.
- 명칭 브라우저 검사 **72조합 통과**: 9개 관련 라우트×2모드×320/390/834/1440px. 표시명·가로 넘침·실행 오류 검사. 검색→평온 상세→확대와 기술 용어 보존도 확인.
- 기존 브라우저 회귀 검사 **15묶음 통과**: 14라우트×4폭 기본 표시, 필터·복귀·차트·날짜·업로드/연결 대기·부가 실패·reduced-motion 등.
- Figma 복제 루트126개(4/24/47/48/3)를 확인했고, 새5페이지의 편집 텍스트에서 이전 감정 표시명0개를 확인했다. 각 복제 배치에서 원본 루트 구조/위치와 텍스트의 전후 fingerprint가 같음을 검사했다. 복제 화면의 프로토타입 대상은 복제 루트로 연결했다.
- HTML의 평온 상세와 Figma 모바일 평온 상세를 대표 시각 검토했다. 모든 화면의 픽셀 비교나 모든 프로토타입 수동 클릭을 완료한 것은 아니다.

명칭 브라우저 검사는 후속 디자인 개선의 사용성 검증이 아니다. 운영3+7 모델/API·실제 설명/이미지 서비스·실기기·스크린리더는 미검증이며, 자세한 범위는 [QA.md](QA.md)에 있다.
