## 실행

이 폴더의 `index.html` 하나를 브라우저에서 열면 실행됩니다. CSS·JavaScript·IBM Plex Sans KR 서브셋 폰트가 내장되어 있습니다. 외부 CDN과 빌드 서버가 필요하지 않습니다. 없는 한국어 글리프는 시스템 글꼴로 대체됩니다. 폰트 라이선스: `docs/licenses/ibm-plex-sans-kr.txt`.

## 실제 동작과 예시 구분

사용자 일기 붙여넣기·TXT 읽기·수정·삭제·날짜 지정·추가·확인·요청 대기까지 로컬 동작합니다. 사용자 텍스트는 서버로 전송하지 않습니다. **운영 일기 3+7 감정 분석은 미연결입니다.** 루트 `/api/analyze`는 기존 6분류이므로 호출하지 않습니다.

별도 예시 버튼만 설계 fixture를 엽니다. 단일 일기 1개, 날짜 있는 4개, 날짜 없는 4개를 구분합니다. 입력한 사용자 글로 예시 확률을 계산하지 않습니다. 카카오톡 PC TXT는 기존 별도 경로와 화자 직접 선택·전체 최근100 기준을 유지합니다.

## 구현

- 동일 화면에서 붙여넣기/TXT 전환, 날짜 선택·복수 기록·미리보기·확인 체크.
- 검토용 화면 제한: 전체10,000자·30개 기록·TXT1MB. 모델 토큰 한도로 확정된 값이 아닙니다.
- 단일 기록은 추이·캘린더·기간·반복 표현 미제공 사유를 표시합니다.
- 복수 기록은 전체 기준 P7 평균→P3 합산, 기록 순서 추이·정확한 값 표·반복 표현을 표시합니다.
- 날짜가 있는 경우에만 일·주·월·캘린더와 상세를 제공합니다.
- 기존 7종 도감·검색·정렬·상세·확대·분류별 흐름·상태 복구·블로그 출력을 유지합니다.
- 1:1/4:5, 골드/잉크, 수치 공개/비공개, Canvas PNG, 기기 공유 또는 다운로드 대체.
- 공유 허용 목록에는 감정·선택 수치·표본·범위·예시 구분만 포함합니다. 원문·화자·파일명·대화방·내부 ID는 제외합니다.
- 라이트·다크·시스템 모드. 입력·결과는 브라우저 메모리에만 유지하며 새로고침 시 초기화됩니다. 표시 모드만 별도 localStorage 키에 보관합니다.

## 개발

기존 vanilla JS 구조와 도메인·공유 코드를 복제 재사용했습니다. 프레임워크나 공용 서버·설정은 변경하지 않았습니다.

```sh
node hw/diary-social-v1/tools/build.mjs
node --test hw/diary-social-v1/tests/diary.test.cjs
```

`diary-core.js`: 입력 계약 초안·검증·비식별 fixture. `diary.js`: 입력·확인·대기·일기 대시보드. 기존 `core.js`, `app.js`, `social.js`, `theme.js`는 새 폴더 내 독립 복제본입니다. 앱은 빌드 산출물 한 파일로 실행됩니다. `dist/`와 `.openai/`는 로컬 QA용으로 저장소 반영에 포함하지 않습니다.
