# 화면별 사용자 행동과 구성

| 화면 | 필요한 이유 / 진입 | 핵심 정보와 행동 | 성공·실패·다음 경로 |
|---|---|---|---|
| 시작 | 서비스와 데이터 범위 이해 | 절차·대표 빈 카드·PC TXT·개인정보 안내 | 업로드 또는 명시적 예시 체험 |
| 업로드 | 파일 형식 확인 | 선택·드롭·파일명·교체·텍스트 수 | 화자 / 오류 후 파일 교체 |
| 화자 | 이름만으로 본인을 판단할 수 없음 | 최근 범위의 화자 목록·개수·직접 입력 | 유효 이름 선택 후 진행 / 불일치 오류 |
| 진행 | 처리·대기·오류를 구분 | 파싱·범위·모델·부가 결과 단계 | 현재 연결 대기 / 재확인·화자 복귀·별도 예시 |
| 대시보드 | 분석 질문의 출발점 | 범위·두 대표값·표본·분포·흐름·반복·달력·도감·설명 | 각 상세 화면 또는 공유 |
| 흐름 | 변화를 지점별로 이해 | 3계열·부모별·7개 보기·계열 체크·값 표·탐지 구간 | 선택 유지 / 분석 불가 공백 / 대시보드 |
| 분포 | 전체 구성과 분모 확인 | 부모 누적·7개 그룹 막대·정확한 표 | 카드별 상세 / 대시보드 |
| 캘린더 | 현재 파일의 날짜 기준 탐색 | 실제 월·기록 날짜·선택일 분포·흐름 | 기간 보기 / 날짜 없음 → 순서 보기 |
| 기간 | 일·주·월 비교 | 집계 단위·표본·전체/7감정 상세·원본 가중 평균 | 날짜 상세 / 기록 없는 구간 공백 |
| 반복 표현 | 어떤 원본에 얼마나 나왔는지 확인 | 정렬·df/tf/등장비율·독립 라벨 개수·원문 근거 | details 펼침 / 후보 없음 / 대시보드 |
| 도감 | 감정 아이덴티티를 유형별로 탐색 | 7유형·검색·부모 필터·정렬·빈 결과 | 카드 상세 / 검색 상태 유지 |
| 카드 상세 | 유형 정보와 결과를 구별 | 빈 슬롯·전체 확률·대표값·이전다음·확대 | 목록 복귀·감정 흐름·공유 |
| 공유 | 개인정보를 통제하며 결과 시각화 | 공개 미리보기·1:1/4:5·골드/잉크·수치 공개 | PNG·시스템 공유·복사 / 실패 재시도 |
| 종합 설명 | 근거를 문장으로 이해 | 동일 JSON의 사실 문장·독립 상태 | 설명 실패 시 재시도 / 통계 유지 |
| 상태 검토 | 중립·empty·invalid·no-time 비교 | 가상 상태 전환·부분 성공 | 정상 예시로 복귀 |

Figma는 화면별 대표 상태를 표현하며 실제 입력 편집과 파일 읽기를 수행하지 않습니다. 프로토타입 버튼은 동일 페이지의 대표 화면/상태로 연결됩니다. HTML은 메모리 상태를 실제로 바꾸며 모델 미연결 경계를 유지합니다. 기간 상세 필터·검색 입력·PNG 내보내기 등 동적 기능의 세부 구현은 HTML과 SDS를 기준으로 합니다. Figma와 HTML의 상태 전환 수와 표현 세부가 모두 일대일 동일한 것은 아니며 이 차이는 QA 대기 사항입니다.
