# MOMENT CARD 통합 UI 구현 설계 2026-11-03

첨부 SDS의 윈도우·anchor·반복 표현·통합 JSON·API 분리 설계를 유지하는 프론트엔드 동기화 보충 명세입니다. 실제 서버 계약과 제안 계약을 구별합니다.

## 구현 단위

기존 프로젝트는 vanilla JS/CSS와 단일 HTML 빌드 구조입니다. React로 임의 교체하지 않았습니다. `scripts/core.js`는 순수 도메인 함수, `scripts/app.js`는 라우팅·뷰·메모리 상태, `scripts/social.js`는 공개 어댑터와 PNG·블로그, `scripts/theme.js`는 표시 모드만 담당합니다. `tools/build.mjs`가 CSS·JS·폰트를 단일 `index.html`에 내장합니다. 현재 소스의 개념 컴포넌트는 함수 단위이며 React Props 인터페이스로 구현했다고 주장하지 않습니다.

## 데이터 연결

| 화면 값 | 원본 필드 / 함수 | 계산과 분모 |
|---|---|---|
| 표본 범위 | totalTextCount/recentCount/target/rows | 전체 → 최근100 → 대상 → 유효 anchor |
| 7분포 | aggregate(rows).leaf | 유효 원본 anchor별 P7 평균, 분모 M |
| 3분포 | parentProbabilities(leaf) | positive=pos1+2+3, negative=neg1+2+3, neutral 그대로 |
| 대표값 | dominantParent/dominantLeaf | 각자 argmax, tie 배열 유지 |
| 흐름 | rows[].probabilities/order | P3 또는 P7, 동일 0–100% Y축 |
| 기간 | groupPeriods(rows,day/week/month) | 유효 timestamp만, 해당 원본 rows 평균 |
| 캘린더 | dateKey(timestamp) | 실제 존재 날짜만; 없는 날 0 대입 금지 |
| 반복 | repeats(target,rows) | df/N과 tf 별도, 원본 ID Set, 독립 라벨 개수 |
| 변화 구간 | segments(rows) | ≥3지점, ≥15%p, 역변화≤2%p, 부모 계열 |
| 설명 | narrative(result) | 같은 summary와 expressions의 로컬 템플릿 |
| 공유 | publicPayload(result) | 7확률·부모합·표본·대표값 재검증 후 공개 허용 목록 |

`docs/design-fixture.json`은 현재 UI와 같은 `demoResult()`로 생성한 비식별 가상 데이터입니다. taxonomy는 UI fixture 식별자이며 학습 라벨 확정 버전이 아닙니다. 표본 43, 부모45/40/15, 소분류18/15/12/17/14/9/15%. 10/22–27 각6개, 28일7개입니다. 고정 확률이므로 변화 구간 없음이 정상입니다. 관측하지 않은 차트 변화를 장식으로 만들지 않습니다.

## 라우트와 상태

`#overview`, `#flow`, `#distribution`, `#calendar`, `#period`, `#repeats`, `#gallery`, `#detail?id=pos_1`, `#share` 등을 사용합니다. 기존 `#cardex`, `#summary`, `#blog`, `#states`도 보존했습니다. state는 파싱·선택 화자·파일명·result·flowView·hiddenSeries·date/month·periodUnit/leaf/key·검색/정렬·scrolls/returnFocus를 메모리에 유지합니다. 새 파일 선택 시 이전 결과·공유 Blob·공개 payload를 무효화하며 파일 읽기 epoch로 오래된 응답을 거절합니다.

통계: empty/unanalyzable/partial/success. 진행은 운영 endpoint 미설정 상태입니다. narrative와 image는 별도 state이며 일부 실패가 result를 삭제하지 않습니다. 캐릭터는 unmapped 상태를 유지합니다. localStorage에는 이 버전의 표시 모드만 저장하며 대화는 저장하지 않습니다.

## API 계약

실제 루트 서버는 `POST /api/analyze {text}`로 이전 6분류를 반환합니다. 새 프론트는 호출하지 않습니다. 다음은 SDS의 **향후** 계약입니다.

| endpoint | 요청 | 반환 / 책임 |
|---|---|---|
| /api/conversation/parse | multipart PC TXT | parse_id, 최근100, 화자, 시간 상태 |
| /api/analysis | parse_id,target_speaker,taxonomy_version | 구조화 7확률·timeline·summary·repeats·segments |
| /api/analysis/narrative | analysis_id | 사실 제한 설명·독립 상태 |
| /api/analysis/image | analysis_id,승인 매핑 버전 | 이미지·독립 상태 / 미승인 시 호출하지 않음 |

어댑터 구현 전 필수 검증: 7ID 정확성·유한 0~1·합계 오차≤1e-6·부모합·대상 anchor·중복 anchor·truncated 거절·모델 버전·요청 epoch. 기존 장문 축소 3→2→1 및 문장 조각 평균 복원은 백엔드에서 구현해야 하며 현재 UI에서 추론하지 않습니다.

## 반응형과 접근성

1440 desktop 다열 요약과 2열 본문, 834 tablet 2열, 390 mobile 요약 우선 단열을 설계했습니다. CSS 1100/767/359 breakpoint, max-width, minmax(0,1fr), 줄바꿈·하단 메뉴·표 가로 탐색을 사용합니다. 핵심 수치는 표 가로 스크롤에만 의존하지 않습니다. 키보드 지점 선택과 값 표, visible focus, dialog 복귀, reduced-motion을 보존합니다. AA 목표이며 실제 렌더·스크린리더·200% 확대·대비 전수 검사는 대기입니다.

## 공유

공개 payload는 원문을 포함하지 않는 새 객체입니다. 포스터 규격1080×1080/1080×1350, 프레임2종, 수치 공개2종. Canvas PNG 후 기기 공유 가능 여부를 검사하고 미지원이면 다운로드를 요청합니다. 복사 실패 시 readonly textarea 선택으로 복구합니다. 생성과 실제 저장·게시 성공을 구분합니다.
