## 충돌과 판단

루트 서버의 6라벨은 새 7소분류와 다른 계약입니다. 이름 변경으로 연결하지 않았습니다. SRS/SDS의 과거 ‘안정’ UI 문구보다 2026-11-02 공통 지침의 ‘평온’을 우선합니다. Figma 미공개 로컬 컴포넌트 키의 파일 간 import가 실패해 실제 코드의 동일 색상·글꼴로 새 로컬 변수와 컴포넌트를 구성했습니다. 외부 디자인 시스템의 Body 스타일은 발견했으나 제품 글꼴과 일치하는 자체 문자 스타일을 사용합니다. Code Connect 파일은 저장소 트리에서 발견되지 않았습니다.

원본 SRS/SDS의 기능·수치는 보존하며 날짜가 붙은 동기화 명세와 사본에 이번 구조를 추가합니다. 기존 문서의 모델 평가 기록을 새 모델 검증으로 해석하지 않습니다.
