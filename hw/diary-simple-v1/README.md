# MOMENT CARD — Diary Simple v1

기존 `hw/diary-social-v1`을 보존한 독립 간소화 프론트입니다.

- [Figma 디자인](https://www.figma.com/design/HwEIUPqCCXzayzB22pLCpr?node-id=3-19)
- [검증 및 제한](docs/QA.md)

## 요청 반영

1. 날짜 선택을 각 ‘기록 1, 2…’ 제목 위로 이동했습니다.
2. 기록 삭제는 기존과 동일하게 해당 기록을 지웁니다. 마지막 기록 삭제 시 빈 기록 한 개를 남깁니다.
3. 결과 첫 화면에는 감정 카드와 공유·상세 분석 행동을 먼저 제공합니다.
4. 그래프·분포·반복 표현·정확한 값 표·캘린더·기간 분석·도감은 ‘상세 분석 새 탭에서 보기’로 탐색합니다.
5. 기존 TXT 입력·내용 확인·카드 편집·PNG·기기 공유·라이트/다크/시스템 모드는 복제해 유지했습니다.

## 실행

`index.html` 하나를 내려받아 브라우저에서 열면 됩니다. HTML/CSS/JS와 IBM Plex Sans KR 서브셋 폰트가 내장되어 있어 별도 설치·CDN·서버가 필요하지 않습니다. 폰트 라이선스는 `docs/licenses/ibm-plex-sans-kr.txt`입니다.

‘예시 카드 미리 보기’를 펼치면 단일·날짜 있는 복수·날짜 없는 복수 기록을 확인할 수 있습니다.

실제 일기 3+7 모델은 미연결입니다. 사용자 글로 예시 확률을 계산하거나 6분류 API를 호출하지 않습니다. 입력한 글은 외부로 전송하지 않습니다.

## 새 탭

현재 파일을 새 브라우저 탭에서 열고, 열어 준 창·동일 출처·요청 토큰을 검증하여 동일한 예시 결과를 메모리에서 전달합니다. 원문 입력을 URL·localStorage에 저장하지 않습니다. 결과 전달 후 opener 참조를 끊습니다. 팝업 차단·시간 초과 시 재시도 안내를 표시합니다. 새로 고침한 상세 탭에는 결과가 없으므로 원래 카드 화면에서 다시 열어야 합니다.
