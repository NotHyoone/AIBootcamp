# 지침 경량화 검증

일상적인 개발 작업에서는 이 문서를 읽을 필요가 없습니다. 사용량 비교를 수행할 때만 참고합니다.

## 적용 내용

- 전역 `~/.codex/AGENTS.md`의 중복 규칙과 완료 보고 형식을 통합했습니다.
- 언어별 상세 규칙은 `~/.codex/guides/software-engineering.md`로 분리했습니다. 필요한 언어 절만 확인합니다.
- 저장소 지침은 백업·생성 HTML·보안 규칙을 유지하면서 탐색과 검증을 변경 영향에 맞추도록 정리했습니다.
- 모델과 추론 설정은 유지했습니다. 추론 수준 변경은 지침 변경 효과와 분리해서 비교합니다.

## 비교 방법

1. 기존 기록에서 비슷한 소규모 작업 3건 이상을 기준으로 선정합니다. 기존 기록에 사용량이 없으면 임의 수치를 채우거나 과거 작업을 재실행하지 말고 미측정으로 표시합니다.
2. 변경 이후 비슷한 범위의 실제 작업 3건 이상을 기록합니다. 비교를 위해 불필요한 구현·도구 호출을 추가하지 않습니다.
3. 가능하면 같은 모델·추론 수준·작업 유형·실행 환경을 맞추고, 대화 길이와 캐시 조건 차이를 비고에 기록합니다.
4. 사용량 화면이나 로그에서 확인할 수 있는 입력·캐시 입력·출력·추론 토큰을 기록합니다. 제공되지 않는 항목은 미측정으로 남깁니다. 추론 토큰이 출력에 포함된 통계에서는 중복 합산하지 않습니다.
5. 도구 호출 수, 검증 결과, 누락·재작업 여부도 함께 비교합니다. 지침 문자 수 감소를 토큰·비용 감소율로 취급하지 않습니다.

## 판정 및 복구

- 필수 백업·보안·생성 파일 보호, 필요한 테스트와 요구사항 충족이 유지되어야 합니다.
- 비교 가능한 작업의 사용량과 도구 호출 수를 품질·재작업 여부와 함께 평가합니다. 표본이 작거나 조건이 다르면 절감률을 확정하지 않습니다.
- 누락이 발견되면 해당 규칙만 보완하고 영향받는 작업에서 다시 확인합니다.
- 변경 전 지침은 `.backups/AGENTS.vNNN.md`와 `.backups/_external/codex/AGENTS.vNNN.md`에 있습니다. 복원 시에도 현재 파일을 다음 버전으로 백업하고 해시를 확인한 뒤 적용합니다. 기존 백업은 삭제하거나 덮어쓰지 않습니다.
- 지침 재로딩 여부는 새 세션에서 확인합니다. 실제 사용량 비교는 후속 작업이 쌓인 뒤 수행하며 이 문서의 빈 칸은 측정 결과가 아닙니다.
