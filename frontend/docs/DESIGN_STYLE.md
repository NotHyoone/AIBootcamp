# 오늘의 모먼트 · 디자인 스타일 가이드

작성 기준: 2026-11-04 현재 작업 트리의 Diary Simple v3. 독자는 UI 개발자·디자이너·인수인계 담당자입니다.

이 문서는 **현재 구현**, **개선 제안**, **미검증**을 구분합니다. 시각적 규칙은 코드 확인 결과이며, 브라우저 전수 검증 결과를 뜻하지 않습니다. 후속 작성 순서는 [문서 작성 계획](DOCUMENTATION_PLAN.md)을 참고하세요.

## 디자인 초기 세팅 반영

팔레트 원본은 `design/tokens/*.json`으로 분리했습니다. `theme.js`는 테마 제어와 저장을 담당하고 생성된 데이터·CSS를 사용합니다. 주요 셸·패널 값은 토큰에 연결했으며 나머지 값은 단계적으로 연결합니다. 빌드는 글꼴 → diary.css → themes.css → generated/tokens.css 순서입니다. [디자인 작업 안내](design/README.md)와 [검토 페이지](design/preview/index.html)를 함께 참고하세요.

## 1. 디자인 방향과 적용 범위

**현재 구현:** ‘오늘의 모먼트’는 기록 작성, 기록별 감정 카드, 보관함과 돌아보기를 연결하는 독립형 HTML 앱입니다. 기본 테마는 따뜻한 종이색과 보라색 강조색을 사용합니다. 기록 화면의 시각적 중심은 입력 영역과 카드이며, 테마를 바꿔도 기록·분석의 의미는 유지합니다.

- 실제 입력은 실행 중 메모리에만 보관하며 분석 대기 상태입니다. 실제 분석·계정·서버 저장은 미연결입니다.
- 예시 모드는 실제 기록과 분리됩니다. 예시 결과를 실제 분석으로 표시하지 않습니다.
- 캐릭터 도형은 정식 디자인 연결 전의 임시 표시입니다.

근거: [README](../README.md), [앱 상태·화면·카드 출력](../scripts/app.js).

## 2. 스타일의 기준 소스

| 역할 | 기준 파일 |
|---|---|
| 테마 원본 / 설정 제어 | `design/tokens/themes.json` / [theme.js](../scripts/theme.js) |
| 공통 화면·레이아웃·컴포넌트 | [diary.css](../styles/diary.css) |
| 테마별 재질·형태·접근성 보정 | [themes.css](../styles/themes.css) |
| 화면 구성·카드 SVG/PNG | [app.js](../scripts/app.js) |
| 통계·도감 화면 | [statistics-view.js](../scripts/statistics-view.js), [catalog-view.js](../scripts/catalog-view.js) |
| 단일 HTML 생성 | [build.mjs](../tools/build.mjs), [shell.html](../templates/shell.html) |

빌드는 `base.css`에서 `@font-face` 선언만 추출하고 `diary.css`, `themes.css`, `generated/tokens.css`를 순서대로 내장합니다. `base.css` 전체와 다른 버전의 디자인 시스템을 현재 화면 규칙으로 사용하지 마세요. 수정은 소스에서 수행한 뒤 프로젝트 폴더에서 `node tools/build.mjs`로 HTML을 재생성합니다.

## 3. 테마와 모드

| ID / 이름 | 현재 화면의 특징 |
|---|---|
| `paper` / 페이퍼 다이어리 | 기본 테마. 종이 질감 배경, 둥근 패널, 카드의 손그림 곡선 |
| `sage` / 세이지 터치 | 녹색 계열, 패널·입력 영역 반경 30px와 부드러운 그림자, 카드 반경 24px |
| `aurora` / 리퀴드 오로라 | 은은한 방사형 배경, 지원 브라우저의 아이콘 배경에 8px 블러 |
| `editorial` / 에디토리얼 모노 | 흑백 계열, 주요 컨트롤 반경 3px, 그림자 제거, 카드의 직선 구분 |
| `retro` / 레트로 플레이 | 24px 격자, 주요 패널·버튼의 2px 테두리, 반경 8px와 3px 오프셋 그림자 |

각 테마는 `light`·`dark`·`system`을 지원합니다. 시스템 모드는 OS 설정을 따라 밝거나 어두운 팔레트로 해석되므로 실제 팔레트는 10개입니다. 기본 선택은 `paper` + `system`입니다.

설정은 `moment-card:diary-simple-v3:appearance`와 `moment-card:diary-simple-v3:color-scheme` 키에 보관됩니다. 잘못된 저장값은 기본값으로 복구하며 저장소 차단 시 현재 실행에서 선택을 적용합니다. 원문과 기록 방식은 이 설정 저장 대상이 아닙니다.

## 5. 타이포그래피와 간격

| 요소 | 현재 기본값 |
|---|---|
| UI 글꼴 | `"IBM Plex Sans KR", sans-serif` |
| 브랜드 | 18px, 600, 자간 -0.7px |
| 큰 제목 `h1` | `clamp(26px, 3.4vw, 44px)`, 행간 1.12, 자간 -2px |
| 패널 제목 `h2` | 23px |
| 작성 입력 | 16px, 행간 1.9 |
| 기록 읽기 | 16px, 행간 1.8, 원문 줄바꿈 유지 |
| 보조 문구·상태 | 주로 12px; 상태 영역 최소 높이 20px |
| 일반 문단 | 행간 1.6 |
| 통계 SVG | 기본 `13px sans-serif`; 모바일에서 차트 text 28px |

현재 주요 셸·작업 열·패널 값은 공통 토큰에 연결했고, 나머지는 컴포넌트별 CSS 값으로 남아 있습니다. 셸 간격 20px, 작업 영역 열 간격 32px, 패널 내부 간격 12px, 목록 간격 8px를 기준으로 인접 요소와 맞추세요. 작은 보조 글씨·SVG 텍스트의 실제 가독성은 별도 확인이 필요합니다.

글꼴을 교체하거나 배포할 때 [IBM Plex Sans KR 라이선스](licenses/ibm-plex-sans-kr.txt)와 HTML에 내장되는 라이선스를 유지합니다.

## 6. 레이아웃과 반응형

| 조건 | 현재 동작 |
|---|---|
| 기본 | 셸 최대 1280px, 중앙 정렬, 패딩 24px 36px, 헤더·본문·푸터 3행 |
| 작성 화면 | 입력과 카드 1:1의 2열 배치 |
| 일반 패널 / 기록 상세 | 최대 너비 각각 760px / 1000px |
| 너비 959px 이하 | 셸 패딩 16px, 1열 배치, 작성·카드 또는 기록·카드를 전환해 표시 |
| 높이 650px 이하 | 셸 패딩 10px 14px, 패널 패딩 14px, 큰 제목 25px, 일부 설명·푸터 숨김 |

너비 분기에서는 패널 패딩 20px와 큰 제목 30px가 적용되며, 높이 분기가 함께 해당하면 뒤쪽 높이 규칙이 이를 덮어씁니다. 앱 높이는 `--app-height`와 `100dvh`를 사용합니다. 긴 원문·설정 내용은 내부 스크롤로 처리합니다.

대표 확인 크기는 1366×768, 1440×900, 390×844, 360×640, 320×568입니다. 실기기 키보드·확대·Safari/Firefox 동작은 미검증 항목으로 남깁니다.

## 7. 컴포넌트와 상태 표현

| 요소 | 현재 규칙 |
|---|---|
| 패널·에디터 | 표면색, 1px 경계, 반경 24px, 패딩 28px; 테마별 덮어쓰기 적용 |
| 주요 버튼 | 강조색 배경, 대비 텍스트, 최소 높이 46px, 패딩 12px 24px, 반경 30px, 600 굵기 |
| 보조·아이콘 버튼 | 투명 배경, 1px 경계, 최소 높이 44px, 반경 30px |
| 입력창 | 투명 배경, 상단 구분선, 크기 조절 비활성, 입력 텍스트는 주 텍스트색 |
| 기록 목록 | 반경 16px, 패딩 12px 16px, 최소 높이 54px, 긴 한 줄 텍스트 생략 |
| 보관함·통계 탭 | 기본 tint, 선택 시 강조색 배경과 대비 텍스트, 기본 최소 높이 40px |
| 테마 선택 | 기본 3열 / 모바일 1열, 선택 라디오·2px 강조 아웃라인 |
| 도감 | 3열, 카드 비율 2:3, 반경 14px, 선택 상태에 3px 아웃라인 |
| 통계 | 추이·월간 기록·분포 전환, 선택 월·날짜와 분석 누락 상태 구분 |

- 포커스: 버튼·입력·textarea에 3px 강조 아웃라인과 3px 오프셋이 있습니다.
- 비활성 버튼: 불투명도 0.5와 대기 커서를 사용합니다. 이미지 저장은 처리 중 중복 실행을 막습니다.
- 오류: 오류색과 상태 문구를 사용합니다. 삭제는 재확인 단계를 거칩니다.
- 빈 상태: 기록 없음, 분석 없음, 분석 대기·실패, 확률 30% 미만의 빈 카드를 구분합니다.
- 상태 안내: [HTML 셸](../templates/shell.html)에 `aria-live="polite"` 안내 영역이 있습니다. 모든 변경이 적절히 읽히는지는 수동 검증이 필요합니다.
- 모션 감소와 강제 색상 모드: `themes.css`에 전환·애니메이션 중지 및 테마 선택 아웃라인 보정이 있습니다.

## 8. 감정 카드와 내보내기

근거: [cards.js](../scripts/cards.js), [app.js](../scripts/app.js)의 `cardSVG()`와 다운로드 처리.

- 카드 표시 비율은 2:3, SVG와 PNG 출력은 1080×1620입니다. 날짜·작성 시각·상태를 표시하고 일기 원문은 제외합니다.
- 반올림 전 최다 확률이 30% 미만이면 빈 카드, 30% 이상~60% 미만은 1단계, 60% 이상~90% 미만은 2단계, 90% 이상은 3단계입니다.
- 동률은 감정 ID 순서로 대표를 선택하고 공동 최다 표시를 남깁니다. 단계는 감정의 강도나 성장 점수가 아닙니다.
- 기록 수정으로 분석 버전이 달라지면 이전 카드·통계·도감 해제 근거에서 제외됩니다. 도감은 7유형 × 3단계의 21개 슬롯입니다.
- 화면에서 계산된 토큰을 SVG의 실제 색상값으로 치환하고 테마별 장식도 반영합니다. 장식의 일부 고정색은 유지됩니다.
- 저장 버튼은 준비된 카드와 빈 카드에 제공하며, 분석 대기·실패 상태와 구분합니다.

## 9. 개선 제안과 미검증 항목

아래 항목은 후속 작업 후보이며 이번 문서 작성에서 UI를 변경하지 않습니다.

| 우선순위 | 개선 제안 | 근거 / 완료 조건 |
|---|---|---|
| P1 | 작은 화면의 조작 영역 점검 | 일부 월 이동 버튼 36px, 탭 40px, 낮은 화면의 탭 32px. 44px 목표 적용 가능성과 화면 수용성을 함께 검토 |
| P1 | 키보드·초점·확대 흐름 점검 | 설정·탭·기록·도감 전환을 키보드로 수행하고 초점 위치와 안내 확인 |
| P2 | 차트 타이포그래피 정리 | SVG의 sans-serif와 UI 글꼴 차이, 모바일 글씨 확대에 따른 겹침 점검 |
| P2 | 정식 캐릭터 자산 연결 준비 | 21개 슬롯별 표현과 미발견 상태, 라이선스·출력 선명도 승인 후 교체 |
| P2 | 최신 화면 증거 정리 | 기존 previews와 browser-results.json의 이전 UI 정보를 현재 검증 근거와 분리 |

**미검증:** 전 테마의 실제 가독성, 스크린리더, 200% 확대, 실기기 키보드, Safari/Firefox. [테마 테스트](../tests/themes.cjs)는 일부 텍스트색 조합의 대비 4.5 이상을 검사하도록 작성되어 있지만, 이번 문서 작업에서 실행하지 않았으며 전체 접근성 준수를 입증하지 않습니다.

## 10. 화면 참조와 유지보수
