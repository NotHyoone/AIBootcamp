# 자산 제작·교체 기준

[자산 목록](../../design/assets/manifest.json)은 원본 위치·상태·권리와 21개 단계 슬롯을 기록합니다. null 경로는 아직 제작하지 않은 자산이며 파일 누락 오류로 취급하지 않습니다.

- 글꼴: base.css의 내장 IBM Plex Sans KR과 기존 라이선스를 유지합니다.
- 캐릭터: pos_1~3, neg_1~3, neutral × stage-1~3의 21개 ID를 유지합니다. 현재 `assets/characters/<emotionId>.png` 7종을 단계 배지와 조합합니다. 단계별 자산을 별도로 제작할 때 manifest의 각 슬롯 경로를 변경합니다.
- 아이콘: 현재 인라인 표현을 보존합니다. 새 자산은 같은 표시 크기에서 선 두께·기준선·레이블을 비교합니다.
- 카드: 2:3, PNG 1080×1620, 날짜·시각·상태를 표시하고 원문은 제외합니다. 텍스트·아트 안전 영역은 정식 아트 제작 전에 확정합니다.
- 차트: 감정 ID·의미색을 유지하고 누락을 중립으로 채우지 않습니다. 범례·수치·선택 표시를 함께 제공합니다.
- 승인: 출처·라이선스·밝음/어두움·작은 화면·PNG 선명도 확인 후 placeholder를 approved로 바꿉니다.

현재 카드 SVG에는 기존 `design-lab/diary-3d-v1`에서 만든 AI 생성 PNG 7종을 내장합니다. 안내용 하트·별을 포함해 9종을 메인에 복사했고 생성 프롬프트는 `assets/characters/prompts.json`에 보존합니다. 새로운 이미지를 생성하지 않았습니다. 카드 SVG와 PNG는 동일한 판정 결과·자산을 사용합니다.
