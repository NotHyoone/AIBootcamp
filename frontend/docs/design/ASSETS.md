# 자산 제작·교체 기준

[자산 목록](../../design/assets/manifest.json)은 원본 위치·상태·권리와 미배정 슬롯을 기록합니다. null 경로는 아직 제작하지 않은 자산이며 파일 누락 오류로 취급하지 않습니다.

- 글꼴: base.css의 내장 IBM Plex Sans KR과 기존 라이선스를 유지합니다.
- 캐릭터: pos_1~3, neg_1~3, neutral × stage-1~3의 21개 ID를 유지합니다. 파일명 제안은 `<emotionId>-stage-<n>.svg`입니다. 확정 전에는 path를 채우지 않습니다.
- 아이콘: 현재 인라인 표현을 보존합니다. 새 자산은 같은 표시 크기에서 선 두께·기준선·레이블을 비교합니다.
- 카드: 2:3, PNG 1080×1620, 날짜·시각·상태를 표시하고 원문은 제외합니다. 텍스트·아트 안전 영역은 정식 아트 제작 전에 확정합니다.
- 차트: 감정 ID·의미색을 유지하고 누락을 중립으로 채우지 않습니다. 범례·수치·선택 표시를 함께 제공합니다.
- 승인: 출처·라이선스·밝음/어두움·작은 화면·PNG 선명도 확인 후 placeholder를 approved로 바꿉니다.

현재 app.js의 아트는 임시 SVG입니다. 정식 일러스트와 새 이미지 파일을 이번 세팅에서 제작하지 않았습니다.
