# 위치와 반응형 규칙

| 조건 | 현재 배치 |
|---|---|
| 기본 셸 | 최대 1280px, 중앙 정렬, 상하 24px·좌우 36px, 헤더/본문/푸터 3행 |
| 작성 작업 영역 | 3:2 2열, 간격 32px, 내부 콘텐츠는 min-height:0 |
| 패널 | 패딩 28px, 내부 간격 12px, 일반 최대 760px·상세 최대 1000px |
| 너비 959px 이하 | 셸 패딩 16px, 1열, 작성/카드 전환, 패널 패딩 20px |
| 높이 650px 이하 | 셸 패딩 10px 14px, 패널 14px, 일부 설명 축약 |

너비·높이 조건이 겹치면 CSS 뒤쪽 높이 규칙이 우선합니다. 앱 높이는 --app-height와 100dvh를 사용합니다. 작성 내용은 .editor-content 내부에서 스크롤하고 기록 버튼은 별도 하단 행에 둡니다. 긴 원문·설정도 내부에서 스크롤합니다. 하단 동작이 가려지지 않는지 확인합니다.

새 영역은 순서·정렬·최소/최대 폭·늘어나는 방향·스크롤 소유자를 정의합니다. 일반 화면에 절대 좌표를 복제하지 않습니다. 카드 SVG는 1080×1620 좌표계를 사용하며 별도 안전 영역 검토가 필요합니다.

와이어프레임은 PC 1366×768, 모바일 390×844의 고정 도형입니다. screens.json의 layout은 의도·주석이며 CSS 생성기가 아닙니다. 다른 크기의 프레임을 만들려면 렌더러의 좌표와 검사도 함께 수정해야 합니다.

카드 버튼 행은 자동 높이이며 480px 이하에서는 기록 읽기가 첫 행을 차지합니다. 본문은 16px, 입력 최소 높이는 180px, 제목은 36px/모바일 28px입니다. 기본 Lemon 테마 패널 반경은 20px, 버튼은 12px입니다.

감정 분포는 3개 대분류와 10개 소분류를 표시합니다. 작은 화면에서는 포커스 가능한 분포 영역 내부를 스크롤하며 페이지 전체나 하단 안내가 밀리지 않게 합니다.
