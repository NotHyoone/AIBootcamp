# 컴포넌트 명세

| 요소 / 구현 | 변형·상태 | 크기·사용 규칙 |
|---|---|---|
| 주요 버튼 .primary | 기본·초점·비활성·처리 중 | 높이 46px 이상, 한 영역의 주 동작 |
| 보조·아이콘 .quiet/.icon | 기본·초점 | 보조 44px 이상, 아이콘에 접근 가능한 이름 |
| 입력 .editor textarea | 빈 입력·작성·오류 | 16px/1.9, 입력 주위 오류 문구 제공 |
| 패널 .panel/.editor | 기본·테마별 재질 | 반경·패딩 토큰, 긴 내용은 내부 스크롤 |
| 기록 .entry | 기본·선택 기록 | 최소 54px, 원문 미리보기 생략, 상세에서 전체 읽기 |
| 탭 .archive-tabs | 기본·선택·초점 | 선택 색과 의미를 함께 표시, 작은 화면 조작 크기 검토 |
| 테마 .theme-option | 기본·선택·초점 | 라디오와 outline, PC 3열/모바일 1열 |
| 카드 .art-card | ready/blank/pending/failed | 2:3, 저장 가능 상태만 저장 동작 제공 |
| 도감 슬롯 | 발견·미발견·선택 | 7유형×3단계, 선택을 색 이외로 구분 |
| 상태 .status/.error | 안내·오류 | 문구와 색 함께 사용, 공통 aria-live 영역 |

주요 스타일은 diary.css·themes.css, 카드·버튼 마크업은 app.js, 도감·통계는 각 view 모듈에 있습니다. 컴포넌트마다 새 런타임 클래스를 만들지 않고 기존 구조를 유지합니다. 모든 상태가 같은 DOM 클래스 변형으로 구현된 것은 아닙니다. 실제 표시 여부는 UI_SPEC와 코드에서 확인합니다.
