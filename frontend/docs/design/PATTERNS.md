# 결합 동작 패턴

| 상황 | 표현과 복구 |
|---|---|
| 빈 입력 제출 | 입력 근처 오류·상태 안내, 입력 유지 |
| 실제 기록 제출 | 브라우저 저장 상태 안내, 분석 대기로 표시 |
| 분석 대기/실패 | 결과 없음과 구분. 실패 예시는 실제 API 연동 완료를 뜻하지 않음 |
| 빈 카드 | 분석은 유효하나 최다 확률 30% 미만, 대기와 구분 |
| 수정 | 버전 증가, 이전 분석·카드·통계·도감 해제 근거 제외 |
| 삭제 | 같은 동작의 재확인 단계, 삭제 후 남은 기록으로 재계산 |
| 내보내기 | 처리 중 중복 실행 방지, 실패 안내와 재시도, 원문 미포함 |
| 필터 상세 진입 | 출발한 목록과 돌아보기 문맥으로 복귀 |

포커스 복원과 상태 안내는 키보드·스크린리더 수동 검토 대상입니다. 입력·스크롤 상태의 모든 복원이 보장된다고 가정하지 않습니다. 앱에 없는 진행률·네트워크 재시도 버튼은 명세 예시만으로 추가하지 않습니다.
