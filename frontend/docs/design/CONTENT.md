# 용어와 UI 문구

실제 기록은 ‘이 브라우저에 보관’, 샘플은 ‘예시’로 표현합니다. ‘안전하게 영구 저장’처럼 현재 동작을 과장하지 않습니다.

| 의미 | 권장 표현 |
|---|---|
| 실제 분석 미연결 | 실제 분석은 준비 중이에요. |
| 빈 기록 목록 | 아직 기록이 없어요. |
| 오류 | 무엇이 안 되었는지와 다시 할 수 있는 동작을 함께 안내 |
| 파괴적 동작 | 삭제 → 정말 삭제하기 |
| 단계 설명 | 분류 확률에 따른 카드 단계이며 감정의 강도가 아님 |

날짜는 YYYY-MM-DD, 작성 시각은 현지 시각으로 표시합니다. 퍼센트 표시는 반올림하되 단계 판정은 반올림 전 값으로 수행합니다. 공동 최다는 별도로 표시합니다. 긴 한국어·영문·숫자 혼합 문구와 줄바꿈 없는 긴 입력을 검토합니다. 실제 원문을 문서나 캡처에 넣지 않습니다.
