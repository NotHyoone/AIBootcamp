# 용어와 UI 문구

실제 기록은 ‘이 브라우저에 보관’, 샘플은 ‘예시’로 표현합니다. ‘안전하게 영구 저장’처럼 현재 동작을 과장하지 않습니다.

| 의미 | 권장 표현 |
|---|---|
| 실제 분석 미연결 | 실제 분석은 준비 중이에요. |
| 빈 기록 목록 | 아직 기록이 없어요. |
| 오류 | 무엇이 안 되었는지와 다시 할 수 있는 동작을 함께 안내 |
| 파괴적 동작 | 삭제 → 정말 삭제하기 |
| 단계 설명 | 분류 확률에 따른 카드 단계이며 감정의 강도가 아님 |

날짜는 YYYY-MM-DD, 작성 시각은 현지 시각으로 표시합니다. 퍼센트 표시는 반올림하되 단계 판정은 반올림 전 값으로 수행합니다. 공동 최다는 별도로 표시합니다. 긴 한국어·영문·숫자 혼합 문구와 줄바꿈 없는 긴 입력을 검토합니다. 실제 원문을 문서나 캡처에 넣지 않습니다.

## 기록 중심 문구

- 초안 트랜잭션 완료: 초안 저장됨. 저장 중에는 초안 저장 중으로 표시합니다.
- 기록 저장 확인: 기록을 보관했어요. 실패·저장 중 상태는 성공과 구분합니다.
- 미연결 분석: 감정 분석은 준비 중이에요. 입력 중 분석 진행을 암시하지 않습니다.
- 카드 확률: 분류 확률 N% / 감정의 강도를 뜻하지 않아요.
- 빈 카드: 뚜렷한 대표 감정이 없는 기록이에요.
- 도감: 기록에서 만난 감정들 / N편의 연결 기록. 완료율을 주 정보로 사용하지 않습니다.

감정명은 기쁨·활력 / 만족·감사 / 안정·자신감 / 불안 / 슬픔 / 분노 / 객관적 서술 / 의문 / 놀람 / 당황을 사용합니다. 중립 안내는 “중립에는 객관적 서술·의문·놀람·당황을 포함해요.”이며, 분포 안내는 “분석된 기록의 평균 분류 확률이에요.”입니다.
