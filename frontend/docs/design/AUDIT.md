# 디자인 현황

## 확인한 사실

- 주 화면: diary.css와 themes.css. base.css는 글꼴 선언만 빌드에 포함합니다.
- 기존 5개 테마와 Lemon 테마 × 2모드 값을 tokens로 관리합니다. 저장 키·공개 테마 API는 유지합니다.
- 기존 WF 14개 + ST 12개, PC·모바일 52개 SVG를 보존합니다.
- 와이어프레임 목록·목적·이동 대상·레이아웃 주석은 screens.json으로 분리했습니다. 좌표·클릭 동작 렌더러는 여전히 build-wireframes.mjs입니다.
- 주요 셸 폭·패딩, 작업 열 간격, 패널 패딩·반경만 공통 토큰으로 연결했습니다. 나머지 CSS의 개별 값은 점진적 전환 대상입니다.
- 카드 SVG는 감정별 3D PNG 7종과 단계 배지를 사용합니다. 30개 도감 슬롯은 같은 감정 자산을 공유합니다.

## 검증 전 조사 항목

작은 월 이동 버튼과 낮은 화면의 탭 크기, 차트 글꼴, 키보드 복귀 초점, 실제 모바일 키보드, 200% 확대를 확인해야 합니다. 확정 결함으로 단정하지 않습니다. 이전 previews와 browser-results.json은 이번 변경의 증거가 아닙니다.
