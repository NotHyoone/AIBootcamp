# 접근성 설계와 검토

다음은 프로젝트 검토 기준이며 전체 접근성 인증 결과가 아닙니다.

| 항목 | 자동·수동 확인 |
|---|---|
| 대비 | 기존 themes.cjs의 주요 텍스트 조합 4.5 검사, 실제 모든 상태는 수동 추가 |
| 키보드 | 작성·설정·탭·기록·도감·삭제·저장 순서, 초점 가림과 복귀 |
| 이름 | 입력 label, 아이콘 버튼 이름, SVG 대체 설명 |
| 상태 | aria-live polite 안내가 적절히 읽히는지 한국어 스크린리더 확인 |
| 크기 | 44px 목표와 화면 수용성 함께 점검, 낮은 화면 탭·월 버튼 조사 |
| 확대 | 200% 확대, 긴 문구·가로 넘침·콘텐츠 접근 |
| 모션·색 | reduced-motion, forced-colors, 색 이외의 상태 구분 |
| 실기기 | 모바일 키보드·주소창 높이, Safari·Firefox |

미실행 수동 항목은 QA에서 미검증으로 기록합니다. 와이어프레임의 축소 표시만으로 앱의 터치·반응형 품질을 판단하지 않습니다.
