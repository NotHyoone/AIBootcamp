# 기초 디자인 규칙

## 기준 데이터

원값은 `design/tokens/primitives.json`, 용도별 별칭은 `semantic.json`, 테마별 연결은 `themes.json`입니다. 테마의 모든 의미색은 원값 참조로 연결합니다. 생성 CSS의 `--color-*`는 새 코드용이며 `--paper`, `--ink`, `--blue` 등은 호환 별칭입니다.

| 영역 | 현재 기준 | 적용 범위 |
|---|---|---|
| 색 | 배경·표면·본문·보조·강조·경계·오류·7감정 | 12개 팔레트와 PNG에 적용 |
| 글꼴 | IBM Plex Sans KR, sans-serif | 본문 UI. 차트·일부 SVG 글꼴은 별도 정리 필요 |
| 글자 | 제목 clamp(26px,3.4vw,44px), h2 23px, 입력 16px, 보조 12px | 기존 CSS 유지, 추출 값은 단계적 연결 |
| 행간 | 본문 1.6, 입력 1.9, 읽기 1.8, 큰 제목 1.12 | 현재 규칙 |
| 여백 | 2·3·4·6·8·10·12·14·16·20·24·28·32·36·48px | 현재 값 보존용 척도, 일괄 정규화하지 않음 |
| 주요 별칭 | shell-padding-block/inline, workspace-gap, panel-padding/radius | 실제 diary.css 연결 |
| 크기 | 일반 조작 목표 44px, 주 버튼 46px | 일부 탭·월 버튼은 목표 미달 가능, 조사 대상 |
| 형태 | 패널 반경 24px, 테마별 30·3·8px 등 | themes.css 예외 유지 |
| 깊이 | 세이지 부드러운 그림자, 레트로 오프셋 그림자 | 재질 CSS 유지, 공통 shadow 토큰화는 후속 |
| 모션 | 기존 전환을 보존하고 reduced-motion 시 중지 | 새 애니메이션 추가 없음 |

## 사용 규칙

색은 색명 대신 용도로 선택합니다. 오류색과 감정색이 유사해도 문구·아이콘·상태를 함께 제공합니다. 장식의 고정색은 카드 아트로 한정하고 본문 색과 분리합니다. 간격은 내부 패딩·동일 그룹·다른 그룹의 관계에 따라 고릅니다. 새 수치를 추가할 때 기존 토큰으로 해결되지 않는 이유를 결정 기록에 남깁니다.

layer-overlay는 향후 겹침 정리를 위한 제안 값이며 현재 앱의 모달 체계를 의미하지 않습니다. breakpoint 토큰은 명세·검사용입니다. 일반 CSS 변수를 @media 조건에 넣지 않으며 실제 분기와 테스트로 일치시킵니다.
