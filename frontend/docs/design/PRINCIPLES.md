# 디자인 원칙

1. 기록 입력과 읽기를 주 콘텐츠로 둡니다. 장식이 본문 가독성을 방해하지 않게 합니다.
2. 실제 기록과 예시 모드를 구분합니다. 미연결 기능을 완료된 결과처럼 표시하지 않습니다.
3. 분석 대기·실패·결과 없음·빈 카드를 구분합니다. 누락 분석을 중립으로 채우지 않습니다.
4. 감정은 평가가 아닙니다. 확률·카드 단계를 감정 강도나 성장 점수로 표현하지 않습니다.
5. 테마가 바뀌어도 정보 순서와 주요 동작은 유지합니다.
6. 파괴적 동작은 재확인하고 다음에 할 수 있는 행동을 안내합니다.

선택이 충돌하면 기록 가독성 → 상태 이해 → 조작 가능성 → 장식 순서로 판단합니다. 이는 프로젝트의 설계 기준이며 사용자 조사 결과를 뜻하지 않습니다.
