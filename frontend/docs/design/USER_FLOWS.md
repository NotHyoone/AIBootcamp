# 정보 구조와 사용자 흐름

주 진입은 일기 작성입니다. 보관함은 지난 기록·돌아보기·캐릭터 도감으로 나뉩니다. 설정은 테마·모드·기록 방식·예시 전환을 제공합니다.

| 흐름 | 화면 순서 | 복귀·예외 |
|---|---|---|
| 실제 작성 | WF-01 → ST-02 | 원문은 메모리만, 실제 분석 미연결 |
| 예시 카드 | WF-06 → WF-02 | 실제 입력의 결과로 표시하지 않음 |
| 기록 관리 | WF-03 → WF-04 → WF-05 | 목록으로 복귀, 삭제는 ST-07 |
| 돌아보기 | WF-07/08/09 → WF-10 → WF-04 | 진입한 통계·목록으로 복귀 |
| 도감 | WF-11 → WF-12/13 → WF-14 → WF-04 | 미발견 슬롯에 연결 기록 없음 |
| 내보내기 | WF-02 → 저장 | 저장 실패 ST-08, 원문 제외 |

실제 작성과 예시 기록은 분리합니다. 현재 메모리 기록은 새로고침하면 사라집니다. 화면 ID는 와이어프레임의 논의 단위이며 앱의 URL 라우트가 아닙니다. 정확한 상태와 전환은 [화면 명세](../UI_SPEC.md)를 봅니다.
