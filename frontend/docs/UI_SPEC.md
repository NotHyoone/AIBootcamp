## 실제 화면 규칙
상단 오른쪽은 보관함(보관 상자)·설정(톱니바퀴) 순서의 선 아이콘 버튼입니다. 아이콘은 24px, 터치 영역은 화면 높이와 관계없이 44×44px이며 테마의 글자색을 따릅니다. 각 버튼은 접근성 이름과 기본 툴팁을 제공하고 Enter·Space로 실행합니다.

진입·복귀 흐름은 [USER_FLOWS](design/USER_FLOWS.md), 조작·복구는 [PATTERNS](design/PATTERNS.md)를 따릅니다.
- WF-01: 빈 입력은 ST-01. 실제 기록 제출은 ST-02이며 모델 호출은 하지 않습니다.
- WF-02, ST-09~12: 예시 결과 카드. 반올림 전 최다 확률 <30% 빈 카드, 30~60% 미만 1단계, 60~90% 미만 2단계, 90% 이상 3단계. 동률 안내를 유지합니다.
- WF-03~05, ST-07: 목록→상세→수정/삭제. 수정하면 기존 분석 버전을 무효화합니다. 하루 한 편/여러 편과 원래 날짜 유지 규칙은 README를 따릅니다.
- WF-06: 테마·모드 선택 즉시 반영, 표시 설정은 localStorage, 실제 기록·초안·기록 방식은 IndexedDB에 저장. 예시 전환은 실제 기록과 분리합니다.
- WF-07~10, ST-04~06: 추이·월간·분포, 날짜 목록. 기록 없음·분석 없음·분석 하루를 구분합니다.
- WF-11~14: 유형·단계별 해제, 미발견, 연결 기록. 유효한 마지막 기록이 사라지면 다시 잠깁니다.
- ST-08: 카드 저장 실패 안내. 분석 실패와 서로 다른 상태입니다.
## 와이어프레임과 앱의 차이
와이어프레임은 고정 날짜·설명용 집계·흑백 도형입니다. 실제 입력·분석·다운로드를 실행하지 않습니다. screens.json의 actions는 화면 링크 목록이며 실제 이벤트 핸들러가 아닙니다. 앱은 app.js의 상태와 뷰 모듈로 전환합니다. 분석 실패는 도메인 상태에 존재하지만 별도의 기존 ST 프레임은 없으며 추가 후보입니다. 긴 원문 스크롤·저장 중 로딩은 주석 중심이고 실화면 확인이 필요합니다.
기록 상세는 카드 앞뒷면을 뒤집어 읽고 별도 확대 읽기 대화상자를 제공합니다. 키보드 Enter/Space와 대화상자 Esc·초점 복귀를 지원합니다. 스크린리더와 물리적 모바일 기기 검증은 별도로 필요합니다. 신규 API·계정·서버 저장은 이번 범위가 아닙니다.


## 통합 화면 추가 규칙

- 6개 테마의 밝음·어두움 모드에서 카드 뒤집기·빛·기울기·모서리·그림자는 공통입니다. 색상은 테마를 따르며 동작 줄이기 설정에서는 애니메이션·빛·기울기를 끄고 즉시 뒤집기를 유지합니다. 보관함 썸네일·도감과 정적 PNG에는 상호작용 효과를 추가하지 않습니다.

- 기본 테마는 Lemon & Cocoa + 밝음이며 기존 선택은 유지합니다. 기존 5개 테마도 계속 제공합니다.
- 카드 앞면은 감정별 3D 캐릭터·감정명·단계·확률·동률 안내를 표시합니다. 뒷면은 기록 본문이며 본문 스크롤·선택 후에는 자동 뒤집지 않습니다.
- ‘기록 크게 보기’는 원문을 텍스트로 삽입합니다. 닫기·Esc 후 실행 버튼으로 초점을 돌려줍니다.
- 보관함은 날짜·시각·감정 상태·첫 줄과 캐릭터 썸네일을 표시하며 360px 미만에서는 1열입니다.
- 저장소 복원 중에는 변경 컨트롤을 비활성화합니다. 저장 실패·충돌은 원문을 유지하고 재시도 또는 복사 후 새로고침을 안내합니다.
- 초안 지우기·기록 전체 삭제는 두 번 확인합니다. 전체 삭제는 표시 설정과 예시 기록에 영향을 주지 않습니다.


## 카드 프레임·조작 단순화 (2026-11-09)

카드 앞면·뒷면·빛·클릭 영역은 공통 2:3 프레임(최대 360×540px)을 사용합니다. 효과 여백 16px을 제외한 가용 크기에 맞춰 축소하며 안내는 프레임 밖에 둡니다. 테마는 색상과 재질을 바꾸며 카드의 기하와 동작은 유지합니다.

카드에는 이미지 저장과 더보기만 기본 노출합니다. 더보기에서 확대 읽기·수정·도감·삭제에 접근합니다. 대기·실패 카드는 다운로드를 제공하지 않습니다. 서비스명은 작성 화면 복귀 버튼입니다. 작성 더보기에서 초안을 지우며 저장 재시도는 저장 실패 시 노출합니다. 삭제는 취소가 기본 초점인 확인 대화상자를 거칩니다. 수정 취소는 원문을 유지합니다.

설정의 기록 방식·예시 모드·데이터 관리는 접이식 항목이며, 예시 전환은 스위치입니다. 통계 종류는 선택 상자, 월은 월 입력으로 조작합니다. 발견한 도감 슬롯은 연결 기록으로 바로 이동합니다. 키보드·터치·Esc·초점 복귀를 검증하며 PNG와 저장 데이터 형식은 유지합니다.
