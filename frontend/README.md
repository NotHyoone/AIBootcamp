## 실행과 보관

`index.html` 하나를 브라우저에서 엽니다. 실제 기록·초안·기록 방식은 메인 전용 IndexedDB `moment-diary-main`에 보관하며 새로고침 후 복원합니다. 표시 설정은 기존 localStorage 키를 유지합니다. 복원 중에는 입력과 변경을 잠시 비활성화합니다. 브라우저 데이터 삭제 시 기록도 사라지며, 파일 URL과 서버 URL은 같은 저장소를 공유한다고 보장하지 않습니다. 계정·동기화·서버 백업과 실제 분석은 연결하지 않았습니다.

설정의 하루 한 편은 오늘 기록을 갱신하고, 여러 편은 새 기록 쓰기마다 항목을 생성합니다. 기록 날짜는 현지 날짜로 자동 결정하며 기존 기록 수정은 원래 날짜를 유지합니다.

## 기록별 카드

기록 ID와 원문 버전으로 분석·카드를 연결합니다. 실제 글은 현재 분석 대기 상태입니다. 설정의 예시 모드에서만 분석된 예시 카드와 수집을 확인할 수 있습니다. 예시 데이터는 실제 기록과 섞이지 않습니다.

10개 감정 중 최다 확률을 반올림 전에 판정합니다. 30% 미만은 빈 카드, 30% 이상~60% 미만은 1단계, 60% 이상~90% 미만은 2단계, 90% 이상은 3단계입니다. 동률은 기존 감정 ID 순서로 대표를 선택하고 공동 최다 표시를 남깁니다. 분석 실패·대기는 빈 카드와 구분합니다. 단계는 감정 강도나 성장 점수가 아닙니다.

같은 캐릭터여도 기록별로 독립된 카드이며 날짜·작성 시각을 표시합니다. 선택한 기록의 카드를 1080×1620 PNG로 저장하며 원문은 포함하지 않습니다. 기존 3D PNG 7종에 중립 소분류 4종의 SVG 표식과 단계 배지를 결합해 10종을 표현합니다. 분석 대기·실패·빈 카드에는 감정 캐릭터를 표시하지 않습니다. 카드 앞면을 탭하면 원문을 읽고, ‘기록 읽기’로 긴 원문을 확대할 수 있습니다. 본문 밖에서 500ms 길게 누르면 빛 효과를 표시합니다.

## 보관함

- 지난 기록: 날짜·작성 시각·카드 상태를 확인하고 기록과 카드를 열어봅니다.
- 돌아보기: 감정 추이·월간 기록·감정 분포를 한 화면에서 전환합니다. 분석 누락을 중립으로 채우지 않습니다.
- 캐릭터 도감: 10유형 × 3단계의 30개 슬롯입니다. 만난 단계만 해제합니다. 같은 슬롯의 마지막 기록을 삭제하거나 수정해 분석이 무효화되면 다시 잠깁니다.

원문 수정은 버전을 증가시키고 분석을 대기로 바꿉니다. 이전 버전 분석은 카드·통계·도감에서 제외합니다. 캐릭터 도감에서 해당 유형·단계의 기록으로 이동할 수 있습니다.

## 소스와 검증

`cards.js`는 카드·수집 판정, `catalog-view.js`는 도감, `statistics.js`는 통계, `app.js`는 기록 상태와 공통 SVG·PNG 출력을 담당합니다. 빌드 시 단일 HTML로 내장합니다.

```powershell
node tools/build.mjs
node --test tests/*.test.cjs
node tests/browser.cjs
node tests/persistence-browser.cjs
node tools/build-wireframes.mjs
node tests/wireframes.cjs
```

브라우저 검사는 Playwright와 Chrome을 사용합니다. `CARDEX_PLAYWRIGHT`, `CARDEX_CHROMIUM`으로 경로를 지정할 수 있습니다. 실기기 키보드와 Safari·Firefox는 별도 수동 검증이 필요합니다.

## 화면 테마

설정에서 Lemon & Cocoa, 페이퍼 다이어리, 세이지 터치, 리퀴드 오로라, 에디토리얼 모노, 레트로 플레이를 선택합니다. 각 테마는 밝음·어두움·시스템 모드를 지원합니다. 저장된 선택이 없거나 유효하지 않을 때 기본값은 Lemon & Cocoa + 밝음입니다. 기존 사용자의 선택은 유지합니다. 선택은 앱 전체와 카드 PNG(1080×1620)에 적용됩니다. 저장소 차단 시 현재 실행에만 적용합니다. 표시 설정과 일기 저장소는 분리되어 있습니다.

테마 검증: `node tests/themes.cjs`. 기존 브라우저 검사와 같은 Playwright·Chrome 경로를 사용합니다.

## 영구 저장과 삭제

초안은 입력 후 500ms, 기록 확정·수정·삭제와 기록 방식은 즉시 저장합니다. 실제 기록은 최대 30편, 기록 또는 초안 하나는 최대 10,000자입니다. ‘초안 저장됨’은 트랜잭션 완료 후 표시합니다. 예시 데이터와 화면 탐색 상태는 저장하지 않습니다.

저장 실패 시 화면의 내용을 유지하며 ‘저장 재시도’를 제공합니다. 다른 탭이 먼저 저장한 경우 덮어쓰기를 중단하므로 현재 내용을 복사한 뒤 새로고침하세요. 저장소 접근 실패나 손상된 데이터가 있어도 메모리에서 작성할 수 있지만 저장 성공으로 표시하지 않습니다. 미저장 변경에는 이탈 경고를 표시합니다.

작성 화면의 ‘초안 지우기’는 초안만, 설정의 ‘이 브라우저의 기록 전체 삭제’는 실제 기록과 초안을 삭제합니다. 두 동작 모두 두 번 확인하며 테마 설정과 예시 데이터는 유지합니다. 기존 Flip 시안의 저장소를 가져오거나 삭제하지 않습니다.

## 기록 중심 UI 개선 (2026-11-09)

작성 화면은 3:2 배치와 분리된 저장 안내, 카드는 직접 읽기·이미지 저장·더보기, 보관함은 본문 미리보기 중심 한 열 목록을 사용합니다. 돌아보기는 월간 기록으로 시작합니다. 기존 7종 캐릭터와 모든 테마를 유지합니다.

검증: `node tests/record-ui.cjs`. 실행 시 비교 보고서 아래에 새 검증 폴더를 생성합니다. [변경 전후 이미지와 검증 결과](../reports/record-ui-2026-11-09/README.md)를 참고하세요.

## 3+10 감정 체계 (2026-11-10)

긍정은 기쁨·활력, 만족·감사, 안정·자신감입니다. 부정은 불안, 슬픔, 분노이며 중립은 객관적 서술, 의문, 놀람, 당황입니다. 카드 배지는 대표 소분류의 소속 대분류를 표시하고, 통계는 소분류 확률을 합산해 대분류 비중을 표시합니다. 두 대표값은 서로 다를 수 있습니다.

도감은 30슬롯입니다. 중립 4종은 기존 중립 PNG에 문서·물음표·느낌표·물음표와 느낌표 표식을 조합하며 이미지 저장에도 적용합니다. 분류 확률은 감정 강도나 모델 정확도가 아닙니다. 30·60·90% 기준은 기존 UI 정책이며 새 모델에 대한 검증 결과가 아닙니다.

예시 65편은 30슬롯을 두 번씩 포함하고 빈 카드·대기·실패·동률·이전 기록 버전 상태를 제공합니다. 실제 기록과 초안의 저장 방식은 유지하고 실제 분석은 연결하지 않습니다. [후속 분석 연동 계약](docs/API_CONTRACT.md)을 참고하세요.

추가 회귀 검증: `node tests/taxonomy-browser.cjs`.
