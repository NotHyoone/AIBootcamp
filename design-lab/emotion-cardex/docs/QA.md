## 대표 시각 검토

HTML Desktop·Mobile Overview 및 Figma Desktop Overview, Mobile Overview·negative Gallery, 신규 커버를 시각 확인했다. 한글 레이블의 잘못된 줄바꿈, 퍼센트 줄바꿈, 대표 카드 하단 잘림을 공통 텍스트/배치 규칙에서 수정했다. 모든83개 상태의 픽셀 단위 비교나 전체 수동 클릭을 완료했다고 주장하지 않는다. Figma 태블릿3개는 정적 레이아웃 검토용이며 전체 프로토타입 이동은 데스크톱·모바일에서 정의했다.

## 대비 검사

주요 CSS 텍스트 조합을 sRGB 상대휘도 식으로 계산했다.

| 전경 / 배경 | 대비 |
|---|---:|
| #18283D / #F6F3EA | 13.43:1 |
| #59677B / #FFFFFF | 5.75:1 |
| #FFFFFF / #264D8B | 8.34:1 |
| #77531B / #F5EBD7 | 5.84:1 |
| #C6D1DF / #18283D | 9.64:1 |

이 조합은 일반 텍스트4.5:1 목표를 만족한다. 전체 화면의 모든 상태·비텍스트 경계·그래프 계열·외부 자산 대비를 검증한 것은 아니며 WCAG 2.2 AA 전체 인증을 의미하지 않는다. 그래프에는 패턴·텍스트 범례·값 표를 함께 제공한다.

## 미검증/운영 선행 항목

- 실제3+7 모델의 학습·검증, 의미라벨·중립 기준·자산 매핑 확정
- SDS의 운영 parse/analysis/narrative/image endpoint와 실제 파일E2E
- 모든 카카오톡 PC 버전·시스템 이벤트·첨부 형식·비정상 파일의 완전한 파서 커버리지
- Kiwi 형태소·불용어 기반 운영 반복 표현 분석(현재 공백1–3gram 데모)
- 모델 토큰 초과의 축소·재분석 및 실측 고조/완화 정확도
- 외부 LLM·이미지 서비스의 장애와 재시도. 현재 실패는 UI 상태 시험이며 외부 API를 호출하지 않음
- 실기기iOS/Android/Safari, 스크린리더, 실제200%확대, 전체 접근성·보안·개인정보 운영정책
- Figma의 모든 세부 날짜·검색어·변형 미리보기를 동적으로 실행하는 기능. 실제 동작은 HTML 데모에서 검증
- 카드팩·희귀도·진화·영구 저장·획득 이력은 범위 밖

실행 환경의 전용 브라우저·폰트 도구는 저장소의 런타임 의존성에 추가하지 않았다. 폰트 원본은 @fontsource/ibm-plex-sans-kr 5.3.0(SIL OFL)이며 UI 글리프 서브셋을 내장했다.
