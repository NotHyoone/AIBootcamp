# Figma 동기화 범위 · 2026-11-02

대상: MOMENT CARD — Emotion Cardex v1, V3 개선 페이지. 기존 v3은 보존하고 v4를 독립 생성했다.

반영: 모바일용 7유형 간결한 목록, 대표 대분류와 최다 소분류의 해석 안내, 관찰 요약 우선 배치, 카드명과 확률 우선 배치, 차트별 단일 Tab 진입 및 좌우/Home/End 탐색. 기존 3→7 필터·검색·정렬·라이트/다크/시스템·날짜·카드 변형은 유지한다. 모델 분류·확률·승인 전 빈 자산 정책은 바꾸지 않았다.

검증: Node 구문 검사, 단독 HTML 생성, 데이터 및 명칭 테스트 22건, 서버 없이 가상 DOM 렌더 스모크 검사(7유형, 관찰 패널 1개, 차트 진입점 1개). Figma 미리보기는 요청에 따라 검증하지 않았다. 브라우저 기반 상호작용·시각 일치·실기기·스크린리더·접근성 전체 검증은 미수행이다.

남은 작업: 모바일의 대표 카드와 지표 영역을 포함한 화면별 상세 시각 일치, Figma의 확대 차트 모달과 HTML의 선택된 감정 흐름 화면 간 차이, 테마 상태별 대비 및 focus 검증, 검색·차트·복귀 브라우저 회귀 검증. Figma는 검색 입력이 정적이고 HTML은 입력 가능하다. 3+7 운영 API와 캐릭터 자산은 미확정·미연결이다.
