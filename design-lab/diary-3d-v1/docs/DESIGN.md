# 부분 3D 디자인 기준

## 재질과 배치
UI 바탕·입력창·목록·차트·메뉴는 불투명한 평면입니다. 배경 블러와 유리 테두리는 사용하지 않습니다.
큰 입체 오브젝트는 감정 카드의 캐릭터 또는 첫 화면의 안내용 하트입니다. 최근 기록 제목에 작은 별 장식 하나를 더합니다.

캐릭터는 같은 둥근 토끼 형태의 불투명 소프트 토이 재질입니다. 좌측 상단 광원과 부드러운 음영, 낮은 채도의 감정별 색을 사용합니다. 하트는 분석 결과가 아닌 첫 기록 안내입니다.

## 색상
색상 원본은 `design.json`입니다. 각 배열은 배경·표면·본문·보조 글씨·강조·강조 위 글씨·캐릭터 무대·경계 순서입니다.
레몬 시안은 밝은 레몬/갈색, 회색 시안은 연회색/검정이며 양쪽에서 캐릭터 색을 공유합니다. 다크 모드는 각각 짙은 갈색과 차콜입니다.

## 화면과 동작
데스크톱은 작성·카드 2열과 하단 요약, 모바일은 한 열입니다. 주요 메뉴는 작성·카드·기록·통계입니다.
기록 수정 시 이전 분석은 무효화되고, 삭제 시 도감과 통계를 다시 계산합니다. 실제 분석 대기·실패·빈 카드는 감정 캐릭터로 대체하지 않습니다.

7감정 PNG는 기쁨(pos_1), 만족(pos_2), 평온(pos_3), 불안(neg_1), 슬픔(neg_2), 분노(neg_3), 중립(neutral)입니다.
3단계는 배지·점 표식으로 표시하고 30/60/90% 기존 경계를 유지합니다.

## 접근성
본문 최소 대비 4.5:1, 주요 버튼 최소 높이 44px, 가시적인 키보드 포커스, 메뉴·차트의 접근성 이름을 유지합니다.
색만으로 감정을 구분하지 않도록 감정명·단계·표정을 함께 제공합니다. 장식 이미지는 스크린리더에서 숨깁니다.
애니메이션·실시간 3D 엔진은 사용하지 않습니다.

## Figma
Figma 플러그인의 figma-use / figma-generate-design 스킬을 사용합니다.
레이아웃은 Auto Layout, 텍스트는 IBM Plex Sans KR 편집 가능한 텍스트 레이어, 아이콘·차트는 벡터, 캐릭터만 PNG 레이어로 구성합니다.
모바일 주요 메뉴, 보관함 탭, 카드→도감→기록 이동을 프로토타입으로 연결합니다. HTML 화면 캡처는 제작 중 비교용이며 최종 화면을 하나의 스크린샷으로 대체하지 않습니다.
