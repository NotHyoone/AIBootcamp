# Diary Flip v1

기존 frontend 단일 HTML을 바탕으로 만든 독립 시안입니다. index.html을 브라우저에서 직접 엽니다. 실제 감정 분석 API는 연결되지 않았고 예시 카드만 분석 결과를 표시합니다.

기록과 초안은 이 브라우저의 IndexedDB에 보관됩니다. 브라우저 저장소 삭제, 시크릿 모드 종료, 브라우저·기기 변경이나 실행 주소 변경 시 복원되지 않을 수 있습니다. 공용 기기 사용에 유의하세요. 저장되지 않은 내용은 복사해 보관하세요. 같은 저장소를 여러 탭에서 수정하면 충돌 안내 후 저장을 멈춥니다.

앞면 클릭으로 일기를 확인하고 앞면으로 복귀할 수 있습니다. 이미지 저장은 기존 예시 카드 기능을 사용하며 원문은 포함하지 않습니다. 브라우저의 움직임 감소 설정을 지원합니다.

검증: 내장 JavaScript 문법 검사 통과. 브라우저 실행은 환경의 보안 정책으로 차단되어 실제 화면, 자동 저장 및 재로드, 키보드, 스크린리더, 모바일과 다중 탭 동작은 검증 대기입니다. 원본 기능의 동작 보장이나 접근성 인증을 의미하지 않습니다.
